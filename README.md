### ✨ Funcionalidades

🎯 **Home Imersiva** - Banner com filme em destaque
🎥 **Filmes** - Lista de populares e Top 10 mais bem avaliados
📺 **Séries** - Catálogo completo de séries populares
🔍 **Detalhes Inteligente** - Funciona tanto para filme quanto para série
▶️ **Trailer & Elenco** - Assista o trailer e veja o elenco completo
❤️ **Similares** - Recomendação de filmes/séries parecidas

### 🛠️ Stack

- **React + Vite** - Base do projeto
- **React Router Dom** - Navegação entre páginas
- **Styled Components** - Estilização
- **Axios** - Consumo da API
- **TMDB API** - Fonte dos dados

### 🚀 Rodando o projeto

```bash
# Clone o repositório
git clone https://github.com/leandro-T-Souza/Dev-Movies-01.git

# Entre na pasta
cd Dev-Movies-01

# Instale as dependências
npm install

# Crie o .env na raiz e adicione sua chave
VITE_API_KEY=sua_chave_tmdb

# Rode o projeto
npm run dev<div align="center">
